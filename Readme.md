# Реєстрація на майстер-клас

Сторінка показує назву події, дату і місце. Форма перевіряє ім'я, пошту і кількість учасників. Якщо дані заповнені, з'являється «Реєстрація успішна!».

Калькулятор рахує вартість квитків. Standard коштує 400 грн, VIP — 800 грн. За 3–4 квитки знижка 10%, за 5 і більше — 20%. Промокод EVENT50 знімає ще 50 грн після відсоткової знижки. Сума не стає меншою за нуль.

Код сторінки зібраний у Cursor. Перевірку форми і розрахунок ціни я проходив по рядках і перевіряв у браузері.
